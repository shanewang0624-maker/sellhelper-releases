# 微信助手 · 发布仓库

> **声明**
> 本软件仅供个人在**自己本机的微信记录**上做整理与摘要，不提供自动回复、群控、自动加好友等能力，以后也不会提供。
> 请勿将本软件用于违反微信平台规则或侵犯他人隐私的用途。

本仓库**只托管发布产物**（安装包与校验文件），**不包含源码**。

---

## 1. 下载与安装

1. 到右侧 **Releases** 下载最新版 `WeChatHelper_vX.Y.Z_Windows_x64.zip` 与 `SHA256SUMS.txt`。
2. 解压到**可写目录**，例如 `D:\微信助手`。
   **不要放 `C:\Program Files`** —— 那里写数据需要管理员权限，会导致软件起不来。
   路径里避免 `#`、`&` 这类符号（中文与空格没问题）。
3. 双击根目录的 **`启动微信助手.vbs`**。
   整个文件夹要保留完整，**不要只拷 exe** —— 运行时和依赖都在里面。

系统要求：Windows 10 / 11 x64，已登录的本机微信，WebView2 Runtime（Win11 自带，Win10 缺失时装一次）。

---

## 2. 首次启动要激活（一机一码）

本软件采用 **Ed25519 离线非对称授权**，**需要有效授权码方可使用**：

1. 首次打开只有一张激活页（这是正常流程，不是报错，也不是装坏了）。
2. 点「复制」拿走本机 **机器码**（形如 `EKX8-8BMM-8GR7-CX5Y`），发给发行方。
3. 收到 **授权码**（形如 `WX1.xxxx.xxxx`）粘进输入框，点「激活」或按 `Ctrl+Enter`。

几点说明：

- 激活为**本机离线验签**：不联网、不上传机器码，断网与内网机器照常使用。
- 机器码由主板/CPU 等硬件特征哈希而来，**不含 MAC 地址**，换 Wi-Fi、开代理都不会变。
- 授权码与机器码绑定。更换主板或重装系统后机器码会变，需要重新申请；**只换硬盘一般不变**。
- 授权到期后回到激活页，**聊天数据一条不丢**，续一张码即恢复。
- 查看当前授权状态：左下角齿轮 → 设置，头像下方那行小字（机器码 · 版本 · 到期时间）。

## 3. 校验文件完整性

```
Get-FileHash .\WeChatHelper_v<版本号>_Windows_x64.zip -Algorithm SHA256
```

文件名里的版本号换成你实际下载的那个。结果应与**那个 Release 附件里的** `SHA256SUMS.txt` 逐字符一致（当前 v2.3.6 是）：

```
17ba1ecc7ebf0dfabbe7acc7fd428ceec08d309191437ea2a0c12d76c2f0410d
```

> 换版本后这一行会变。请以**你下载的那个 Release 附件**里的 `SHA256SUMS.txt` 为准，不要照抄 README 里的历史值。

> ⚠️ **关于系统提示"未知发布者"**：本版本**未购买商业代码签名证书**，Windows SmartScreen 可能弹窗拦截。
> 这是未签名的正常表现，不是文件损坏。点「更多信息 → 仍要运行」，并用上面的 SHA-256 校验完整性。

## 4. 隐私

- 聊天记录的解析、索引、存储全部在本机完成，不向开发者服务器发送任何聊天内容。
- 本版本**不含任何远程统计/遥测**。
- 唯一的外发是你自己配置的 AI 接口，以及你自己填的 Webhook 地址。
- 可把指定会话设为隐私屏蔽，过滤发生在数据层，Agent 拿不到内容。
- **手机看板也不出局域网**：手机端是这台电脑自己起的一个网页，没有中转服务器、没有云端账号。
  挡三层：监听地址（关掉开关就只听本机）、6 位配对码换来的设备令牌、只读路径白名单（写接口一律 403）。
  手机上只能看（简报 / 会话 / 摘要 / 搜索 / 问一句），改设置、删数据、看密钥都做不到。
